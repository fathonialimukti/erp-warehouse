# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(v2.1). Be kind, assume good intent, no harassment.

Instances of unacceptable behavior may be reported privately to the repo
maintainer (see the repo owner profile). All complaints are reviewed
confidentially; enforcement follows the Covenant's guidelines.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
