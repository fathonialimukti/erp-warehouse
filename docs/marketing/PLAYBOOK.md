# From Nothing to Closing — The Playbook (research-backed)

**Status:** plan, no code changed. Grounded in [`RESEARCH.md`](RESEARCH.md) (69 sources, Nov 2026).
**Correction to earlier plan:** 2 months to a full buyout was optimistic. Realistic: **paid pilot in
4–8 weeks**, **first full buyout in 3–6 months**. A WMS buyout in the $25K–$80K range has a
**45–90 day sales cycle** [39].

---

## The one best step for you right now

> **Stop building product. Get one warehouse to pay you a small pilot fee.**
> Everything else — site, directories, reviews — is support for that goal.

A paid pilot is the shortest path to money, proof, and a reference. It de-risks the full buyout for
both sides. Free pilots attract disengaged users; a payment signals real budget and intent [7][8].

---

## What you are actually selling

Not "source code." You are selling a **solved warehouse problem + permanent ownership**:

> "A complete WMS, installed on your infrastructure, configured to your workflows, with the source
> code included so you own it — one payment, no subscription."

Source code is the proof of ownership, not the product. Sell against "permanent operational
control," not against cheap scripts [RESEARCH §1].

## Stage-by-stage, with inputs and outputs

### Stage 0 — Offer spec (2 days)

| Input                                                                                                 | Action                                                                                            | Output                  |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------- |
| `PRODUCT.md`, your constraints                                                                        | Fix name, 3 one-time tiers, deliverables, license, support, payment terms, customization boundary | One-page **Offer Spec** |
| **Gate:** In 30 seconds you can say what they get, what it costs, what you will/won't configure.      |
| **Numbers to use (anchors):** base license $15K–$45K; customization $5K–$20K; pilot fee 10–30% of     |
| year-one value, credited against buyout; optional maintenance 15–20%/yr; managed hosting $200–$500/mo |
| [RESEARCH §7].                                                                                        |

### Stage 1 — Proof from zero (weeks 1–2)

| Input                                                                                              | Action                                                                                                                                                    | Output                                                                         |
| -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Demo app, seeded data                                                                              | Give 3–5 small warehouses free/discounted early access **in exchange for feedback + a review + reference rights**; record demo video; capture screenshots | Demo URL, 60–90s video, 8–10 screenshots, 3–5 reviews, 1–2 referenceable names |
| **Gate:** You can show a running system and at least 3 people saying it works.                     |
| **Reality check:** ~1% of review requests convert → ~100 contacts per review; budget $250–$500 per |
| review. Put the review commitment **in writing** in the pilot agreement [RESEARCH §3].             |

### Stage 2 — Selling surface (weeks 2–3, build step)

| Input                                                                           | Action                                                                                                   | Output                                                             |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Offer spec + proof                                                              | `/features`, `/pricing`, `/about`, `/contact`, `/faq`, privacy/terms, working lead capture, booking link | A stranger can understand, see proof, and contact you in 3 minutes |
| **Gate:** "what is it / how much / how do I buy" answered without emailing you. |

### Stage 3 — Attention (weeks 1–8, in parallel)

| Channel                                               | Input                                                                            | Output                   | Expect                                |
| ----------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------ | ------------------------------------- |
| **Cold email**                                        | 500–1,000 ops decision-makers, separate domain, 5-email sequence                 | 1–3 booked calls         | 0.84% reply, ~1 call/871 contacts [4] |
| **LinkedIn**                                          | Sales Navigator, 20 personalized connects/wk                                     | 2–5 warm convos          | InMail 18–25% response [27]           |
| **Directories**                                       | Free G2/Capterra/GetApp/Software Advice profiles + reviews                       | Foundation, ~0 leads now | Nothing until 10+ reviews [5]         |
| **Communities**                                       | Genuine participation (r/logistics sticky thread, IWLA, warehouse-logistics.com) | 0–2 warm leads           | Slow, trust-based                     |
| **Partners**                                          | 3PL/ERP consultants, 10–15% referral fee                                         | 0–1 intro in 60 days     | 2–4 months to develop                 |
| **Skip Product Hunt** — wrong audience [RESEARCH §2]. |

### Stage 4 — Discovery (per lead)

| Input                                                                                          | Action                                                                                                    | Output                                |
| ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| Lead + `discovery-checklist.md`                                                                | Ask "which process do you want to change?"; quantify pain; qualify budget/authority/timing; map to config | **Workflow → Config memo** + go/no-go |
| **Gate:** You can restate their pain in their words and name the exact pipelines you'd change. |

### Stage 5 — Demo

| Input                                                                                                 | Action                                                                                           | Output                            |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------- |
| Memo, demo env, `demo-script.md`                                                                      | Live software only; show their scenarios; ask "does this match your team?"; show configurability | Agreed customization list + scope |
| **Gate:** Buyer says "that's what we need." **Send written recap within 24h** (+35% close rate) [66]. |
| Do not discuss price in the demo [13].                                                                |

### Stage 6 — Paid pilot proposal (the close, part 1)

| Input                                                                                                | Action                                                                                                                                                                       | Output                       |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Memo + demo                                                                                          | Written 1–2 page pilot agreement: one site, 1–2 workflows, 60–90 days, 2–4 success metrics, fee $3K–$8K, 50% upfront/50% day 30, auto-convert clause, mutual NDA, data terms | Signed pilot + first payment |
| **Gate:** Money before work starts. Use Founding Partner framing: 15–25% buyout discount in exchange |
| for case study + reference calls [8].                                                                |

### Stage 7 — Full buyout (the close, part 2)

| Input                                                                                               | Action                                                                                         | Output                  |
| --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------- |
| Pilot results                                                                                       | Proposal within 24h of verbal yes; e-sign; license/assignment agreement; SOW; payment 30/40/30 | Signed buyout $20K–$60K |
| Use **present-tense** IP assignment ("assigns," not "will assign") [55]; cap liability at fees paid |
| [52]; tie assignment to final payment [58]. **Never deliver full source before final payment.**     |
| Handover includes a **rebuild test**: their IT deploys from delivered files alone [54].             |

### Stage 8 — Compound

| Input         | Action                                                                                          | Output                                                |
| ------------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| Live customer | Review at peak satisfaction; case study within 60 days; 10–15% referral fee; specific intro ask | Case study, 3–5 reviews, 1 referral → back to Stage 1 |

## Handling "we want SaaS, not source code"

**Acknowledge → probe → reframe** [24]: find the real driver (upfront cost / no IT / maintenance /
vendor risk), then answer with 5-year TCO, optional managed hosting, 90-day support + retainer, or
source-code escrow (Codekeeper from $179/mo [56]). If they want fully managed cloud with no IT and
are not regulated — **qualify out**, don't spend 45 days [39].

## What not to do

- Don't build more product before a buyer conversation.
- Don't list on directories before site/contact work, and don't expect leads before 10+ reviews.
- Don't pay for ads/leads before free channels and a closing process are proven.
- Don't do free customization beyond tightly scoped discovery.
- Don't invent proof; don't lead with "I sell source code."
- Don't discount >30%; frame first-customer discount as Founding Partner.
